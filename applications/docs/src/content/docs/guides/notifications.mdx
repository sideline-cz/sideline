Reminders are Sideline's most-loved feature. They make sure nobody has to manually chase players for RSVPs.

## When reminders fire

Sideline sends one reminder per event, at a configurable time of day on a configurable number of days before the event. For example, the default configuration fires at **18:00** on the day that is **1 day before** the event, evaluated in the team's configured timezone (default: `Europe/Prague`).

The exact timing is configurable per team from **Team settings → Discord**:

| Setting | What it controls |
|---|---|
| **Enable RSVP reminders** | The on/off switch for the whole feature. Turn it off and no reminders are sent for the team. |
| **Days before event** | How many days before the event start the reminder fires. `0` means the morning of the event itself, not "off" — use **Enable RSVP reminders** to turn reminders off. |
| **Per event type** | Optional per-event-type lead times that override **Days before event**. Leave a box blank and that type uses the team-wide value. |
| **Time of day** | The local time (in the team's timezone) at which the reminder fires. Must be 23:54 or earlier. |
| **Timezone** | An IANA timezone name (e.g. `Europe/Prague`, `America/New_York`) used to evaluate the reminder time. |
| **Reminders channel** | Not used to post reminders — reminders are DM-only (see below). It only resolves the deep-link fallback included in a reminder DM when the member has no personal events channel to link to. |

### Different lead times per event type

A tournament usually deserves more notice than a regular training. Under **Days before event** there is a **Per event type** box for each of the six event types (training, match, tournament, meeting, social, other).

- Leave a box **blank** and that type uses the team-wide **Days before event** value — this is the default, so a team that ignores this section behaves exactly as before.
- Type a number and events of that type use it instead. For example, **Days before event** `1` with **Tournament** set to `3` reminds one day before trainings and three days before tournaments.
- `0` is a real value here too, meaning the day of the event — it is not the same as blank.

The timing is still per team: every member of the team gets the same lead time for a given event type.

## Where reminders go

- Reminders are **DM-only**. The bot sends a direct message to each non-responder — nothing is posted to any Discord channel.
- Reminders are **one-off sends** — once the reminder is sent, the event is marked so it won't fire again.

## Who gets pinged

Only players who are members of the event's **member group** (and any of its sub-groups) who haven't RSVPed yet. Once someone clicks Yes / Coming later / Not sure / No, they drop off the reminder list. Members who turned off **Remind me by DM** in their own [event preferences](#per-user-preferences) are skipped too, regardless of whether they've responded.

The bot sends a direct message to each remaining non-responder who has a linked Discord account. The DM links to that member's own personal events channel; if they don't have one, it falls back to the team's configured reminders channel, and finally to a generic link into the Discord server if neither is available.

## Disabling reminders

Per-team: from **Team settings → Discord**, turn off **Enable RSVP reminders**.

<Aside type="tip" title="Reminder hygiene">
  Reminders are effective when they're rare enough to matter. One well-timed reminder the day before is more effective than multiple noisy pings. Trust the defaults.
</Aside>

## Per-user preferences

The timing (days before, time of day, and any per-event-type lead times) is still team-wide, but you control your own reminder DM from your Sideline profile: open your **profile page** on the web app and find the **My events in Discord** card for the team (shown for every team you're connected to via Discord). Turn off **Remind me by DM** and the bot stops sending you the reminder entirely — there's no other channel it falls back to, so if you rely on the reminder, leave this on.

The same card has two more toggles that affect how events look in Discord:

- **Show who's going** — turn this off to hide the list of names on your own event cards (in your personal channel and in `/event list`). The ✅/❌/🕒 counts and the **Attendees** button stay either way — this only hides names, and only on cards only you see.
- **My event channels** — switch from one combined events channel to three (trainings, tournaments, and everything else). See [Personal event channels](/guides/discord-integration/#personal-event-channels) for what this does and its one-way trade-off.

Changes take a few minutes to apply — the bot picks them up on its next pass rather than instantly.
